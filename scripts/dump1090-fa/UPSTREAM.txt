Integration differences: fixed 2.4 MS/s unsigned interleaved I/Q, no bit
correction, no DF24, no Mode A/C, no automatic gain adaptation. DF11 acquisition
and uncorrected DF17/18 seed the upstream recent-ICAO filter. Address-parity
messages require a recent address, as upstream does. Only validated DF17 feeds
AirWSJT-X's existing aircraft decoder; other accepted Mode S formats are
diagnostic counts, not ADS-B aircraft. Per-frame CRC/timestamp evidence is
emitted as diagnostics. Windows capture, queue and lifecycle are app-owned.

GPL-2.0-or-later upstream code is combined under GPL-3.0-or-later, consistent
with AirWSJT-X. COPYING contains upstream GPLv2; COPYING-AirWSJT-X beside the
executable contains GPLv3. All adapted source and build files are shipped.
